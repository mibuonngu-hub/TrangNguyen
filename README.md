HR Attrition Prediction Project
A data analytics and machine learning project focused on predicting employee attrition and identifying key turnover factors, enabling organizations to implement effective employee retention strategies.
Tech Stack & Libraries
Language: Python
Libraries: Pandas, NumPy, Scikit-learn, Imbalanced-learn (SMOTE, ADASYN)
Algorithms: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, SVM, MLP
